상담 일정 위젯 선생님 사용법

PWA 설치부터 일정 등록, 알림함 확인, 학생 계정 카드 인쇄까지

빠른 순서 처음 사용하는 선생님은 아래 순서대로 진행하면 됩니다.

  1. PWA 웹앱으로 설치하기
  2. 선생님 계정으로 로그인하기
  3. 상담 일정 추가하기
  4. 학생 신청 안내하기
  5. 신청 확인, 확정, 상담 완료 처리하기
  6. 학생 계정 카드 인쇄하기
  7. 상담횟수 확인하기

1. PWA 웹앱으로 설치하기

접속 주소: https://coffee-bucket.github.io/schedule//

설치하고 작업표시줄에 고정하시면 일반 앱처럼 바로 열 수 있습니다. 브라우저 주소창을 매번 입력하지 않아도 됩니다.

PC 크롬 또는 엣지

  1. 크롬/엣지에서 위 주소로 접속합니다.
  2. 주소창 오른쪽의 설치 아이콘 또는 메뉴의 앱 설치를 누릅니다.
  3. 설치 후 바탕화면 또는 시작 메뉴에서 상담 일정 앱을 실행합니다.

안드로이드 휴대폰

  1. 크롬에서 접속합니다.
  2. 오른쪽 위 메뉴 ⋮를 누릅니다.
  3. 홈 화면에 추가 또는 앱 설치를 선택합니다.

아이폰 또는 아이패드

  1. Safari에서 접속합니다. 크롬 앱이 아니라 Safari를 권장합니다.
  2. 공유 버튼을 누릅니다.
  3. 홈 화면에 추가를 선택합니다.

알림 허용

학생 신청 알림을 받으려면 앱 상단의 알림 켜기를 누르고 브라우저 알림을 허용합니다.

알림이 차단된 경우 브라우저의 사이트 설정에서 알림을 다시 허용해야 합니다.

2. 선생님 계정으로 로그인하기

  1. 설치한 앱 또는 웹주소를 엽니다.
  2. 선생님 계정과 비밀번호를 입력합니다.
  3. 담임 선생님 계정은 본인 학년/반이 자동으로 선택됩니다.
  4. 관리자 계정은 학년과 반을 선택해서 이동할 수 있습니다.

3. 상담 일정 추가하기

  1. 화면 상단에서 날짜, 교시, 장소를 입력합니다.
  2. + 일정 추가를 누릅니다.
  3. 등록된 일정은 일정 탭에 날짜별로 표시됩니다.

장소 예시: 교무실, 진로상담실, 2층 상담실

장소를 입력하지 않으면 기본 장소가 사용됩니다.

4. 학생에게 신청 방법 안내하기

  1. 학생에게 계정 카드에 적힌 주소 또는 QR로 접속하게 합니다.
  2. 학생은 학번과 비밀번호로 로그인합니다.
  3. 원하는 상담 일정을 선택하고, 필요한 경우 메모를 작성한 뒤 신청합니다.
  4. 학생이 작성한 메모는 선생님 화면의 대기와 알림함에서 확인할 수 있습니다.

5. 신청 확인, 확정, 상담 완료 처리하기

탭사용법
알림함학생 신청과 변경 내역을 확인합니다. 새 알림은 위쪽에 표시되고, 지운 알림은 지난 알림으로 아래쪽에 남습니다.
대기아직 확정되지 않은 신청을 봅니다. 학생 메모와 신청 일정을 확인한 뒤 확정할 수 있습니다.
확정확정된 상담 일정을 확인합니다.
일정전체 일정을 보고, 직접 학생을 배정하거나 상담 완료 처리를 할 수 있습니다.

상담 완료 처리를 누르면 해당 학생의 상담 회차가 올라가고, 학생은 다음 상담을 다시 신청할 수 있습니다.

6. 학생 계정 카드 인쇄하기

  1. 학생계정 탭을 엽니다.
  2. 선택한 학급의 학생 계정 목록을 확인합니다.
  3. 인쇄를 누르면 학생별 카드가 새 창으로 열립니다.
  4. 인쇄된 카드를 점선 기준으로 잘라 학생에게 나누어 줍니다.

계정 카드에는 학생 이름, 학번, 비밀번호, 상담사이트 QR이 들어갑니다.

QR 주소: https://yjbs1.netlify.app/

개인정보 주의: 계정 카드에는 비밀번호가 포함되어 있습니다. 출력물은 학생 본인에게만 전달하고, 남은 출력물은 안전하게 보관하거나 폐기합니다.

7. 상담횟수 확인하기

  1. 상담횟수 탭을 엽니다.
  2. 학생별 누적 상담 완료 횟수를 확인합니다.
  3. 최근 상담 일정이 있으면 함께 표시됩니다.

자주 생기는 문제

상황해결 방법
화면이 예전 그대로 보입니다.앱을 새로고침하거나 완전히 종료 후 다시 엽니다.
알림이 오지 않습니다.브라우저 사이트 설정에서 알림 허용 여부를 확인합니다.
인쇄 창이 열리지 않습니다.브라우저 팝업 차단을 해제한 뒤 다시 인쇄를 누릅니다.
QR이 인쇄되지 않습니다.인쇄할 때 인터넷 연결을 확인합니다. QR 아래의 주소를 직접 입력해도 됩니다.
학생이 로그인하지 못합니다.학생계정 탭에서 학번과 비밀번호를 다시 확인한 뒤 안내합니다.
